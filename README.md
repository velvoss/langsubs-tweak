# LangSubsTap 3.4

تويك (dylib) يُحقن في Nuvio لتحويل أي ترجمة إلى أداة تعلّم لغات:
انقر كلمة داخل المشغّل، اسمع نطقها، اقرأ معناها وتعريفها، واحفظها لمراجعة لاحقة.

## الميزات
- **بطاقة كلمة مضغوطة** أسفل الترجمة: خط وأزرار ومسافات أصغر، خلفية ضبابية، وأزرار «أتعلمها / أعرفها / إغلاق».
- **نطق فوري** عبر `AVSpeechSynthesizer` مع كشف لغة الكلمة تلقائياً (`NaturalLanguage`)، ونطق الترجمة بلغة الهدف.
- **أزرار تظهر عند تحديد كلمة فقط**: زر نطق الجملة على يمين النص، وزرّا السابق/التالي على يمينه ويساره،
  والترجمة بحد أقصى سطرين، ترتفع قليلًا فوق البطاقة دون أن تلتصق بالحافة العلوية.
- **قاموس إنجليزي** (`dictionaryapi.dev`): رمز صوتي، نوع الكلمة، وتعريف.
- **ترجمة الكلمة والجملة كاملة** (Google Translate ثم MyMemory كبديل) مع تخزين مؤقت.
- **تلوين الكلمات حسب حالتها**: جديدة / أتعلمها / أعرفها.
- **مكتبة كلمات** مع بحث وتصفية، تفاصيل لكل كلمة، وحذف/تغيير الحالة بالسحب.
- **مراجعة سريعة** ببطاقات تعليمية (إظهار المعنى ثم تقييم نفسك).
- **إعدادات كاملة**: النطق التلقائي، سرعة الصوت، لغة الترجمة، ترجمة الجملة، القاموس،
  تفعيل داخل المشغّل، ألوان الكلمات، حجم الخط، شفافية الخلفية، ارتفاع الترجمة،
  إظهار زر الترس العائم، تصدير/استيراد JSON، ومسح البيانات.

## الوصول إلى Lang Subs
1. **زر عائم (FAB)** على الشاشة الرئيسية: قابل للسحب، ويعرض شارة بعدد كلمات «أتعلمها».
   النقر يفتح: الكلمات المحفوظة / مراجعة سريعة / الإعدادات.
2. **زر الترس** أسفل المشغّل (يظهر عندما تكون بطاقة الكلمة مغلقة، ويمكن إخفاؤه من الإعدادات).
3. **إيماءة 3 أصابع** (ضغط مطوّل 0.7 ثانية) في أي مكان لفتح الإعدادات مباشرة.

يمكن لأي تطبيق مضيف أيضاً إرسال الإشعار `LangSubsTapOpenSettings` لفتح اللوحة.

## البناء
- على ماك: `./build.sh` (يتطلب Xcode Command Line Tools).
- أو ارفع المجلد إلى GitHub: الـ workflow يبني `LangSubsTap.dylib` ويرفعه كـ artifact.

## الحقن
- Sideloadly: Advanced Options → Inject dylibs/frameworks → أضف `LangSubsTap.dylib`.
- أو LiveContainer: أضفه كتويك للتطبيق.

## افتراضات وملاحظات
1. **libmpv عبر `dlsym`**: إذا كانت MPVKit مدمجة ستاتيكياً ومخفية الرموز، سيظهر في السجل
   `libmpv symbols not found` ولن تعمل الترجمة التفاعلية. افحص `nm -gU` على الإطار.
2. **مقبض mpv**: يُقرأ من الـ ivar المسمّى `mpv` في `MPVPlayerViewController`.
3. يخفي ترجمة mpv الأصلية (`sub-visibility=no`) ويرسم بدلها، ويعيدها عند الخروج.
4. الترجمات الصورية (PGS/DVD) تُترك لـ mpv لأنها ليست نصية.
5. Nuvio يسمح بـ ATS arbitrary loads؛ الاتصالات هنا HTTPS.
6. بياناتك محلية في `NSUserDefaults` تحت `LSWordsV3` (مع ترحيل تلقائي من الإصدارات السابقة).
7. لمراجعة السجل: Console على الماك، ابحث عن `[LangSubsTap]`.
